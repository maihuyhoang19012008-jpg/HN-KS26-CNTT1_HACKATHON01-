# RUA XE WEBSITE FINAL

## Thư mục
| Thư mục | Nội dung |
|---|---|
| RUA | Quản lý quy trình rửa xe, danh sách khách hàng |
| XE | Thông tin xe, loại xe, trạng thái bảo dưỡng |
| WEBSITE | Mã nguồn giao diện, trang báo giá, API |
| FINAL | Báo cáo tổng hợp, file dữ liệu xuất ra |
